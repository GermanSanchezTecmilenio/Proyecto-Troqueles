# Documentacion funcional

Esta carpeta conserva solo documentacion vigente para operar, probar y mantener el sistema de Tornos SA de CV.

El proyecto usa Node.js/Express en `src/`, frontend estatico en `public/`, migraciones SQL en `db/migrations/` y MySQL como base de datos.

## Archivos

| Archivo | Uso |
|---|---|
| `api-rest.md` | Rutas REST disponibles por modulo. |
| `modelo-datos-inicial.md` | Tablas principales y reglas de datos en uso. |
| `seguridad.md` | Variables, autenticacion, sesiones y checklist de produccion. |
